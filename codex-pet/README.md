# Codexひよこ

Codexの状態をひよこの表情で確認する、小さなローカルステータスペットです。

## 起動

このリポジトリを `http://127.0.0.1:5500/` で配信している場合は、次のURLを開きます。

`http://127.0.0.1:5500/codex-pet/`

## 状態の切り替え

- 画面上の「作業中」「待機中」「確認待ち」「完了」「エラー」をクリック
- `?status=working` または `#working` のようにURLで指定
- 外部ページから次のメッセージを送信

```js
window.postMessage({ type: "codex-status", status: "waiting" }, "*");
```

現在は状態表示のUIと外部メッセージ受け取りまでを用意しています。Codexの内部状態を自動取得するには、後からローカル連携部分を追加します。
